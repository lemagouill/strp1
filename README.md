# Parents. Again. — Two Kids. One Wild Time.

A clean, personal family and parenting blog for the Thomson family (Graham, Christina, Shephard, and Alex).

## 👨‍👩‍👧‍👦 Sections Included

- **Header**: Clean dark navigation with links to Family Photos, Stories & Updates, Parenting Tips, About, and Search.
- **Hero**: Father & child hero banner with bold headline and family credits.
- **Intro Banner**: "Two Kids. One Wild Time." storytelling intro on soft blue pastel background.
- **Featured Cards**: "See what's new with the Thomsons" with interactive modal views:
  - Family Photos Gallery
  - Stories & Updates (full family articles)
  - Practical Parenting Tips & Hacks
  - About the Thomson Family
- **Footer**: Copyright notices, social media links, and site policies.
- **Cloaking Integration**: Ready with `index.php`, `white.php`, and `assets/`.

## 🛠️ Development & Build

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Compile for production
npm run build
```
