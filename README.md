# Corsovault — Global Payment Gateway Consulting & Setup Support

Site officiel de l'agence de conseil **Corsovault**, spécialisée dans l'intégration, la sécurisation et l'optimisation des passerelles de paiement internationales (Stripe, PayPal, Adyen, Braintree).

## 🚀 Fonctionnalités & Contenu Intégré

1. **Guide des Meilleures Pratiques** :
   - Stripe & 3D Secure 2 (SCA, exemptions TRA, webhooks fiables, codes d'exemples).
   - PayPal Commerce Platform & Braintree (Smart Buttons, Protection Marchand, Devises multiples).
   - Méthodes de paiement locales & alternatives (iDEAL, Bancontact, Klarna, Pix, etc.).
   - Prévention des fraudes & litiges (Seuils Visa/Mastercard, RDR Verifi, alertes Ethoca).

2. **Formulaire d'Audit & Contact Interactif** :
   - Diagnostic en 3 étapes avec calculatrice de potentiel de conversion.
   - Validation complète des champs, respect strict du RGPD.

3. **Études de Cas & Témoignages** :
   - Résultats chiffrés réels/fictifs pour E-Commerce DTC, SaaS et Marchés du Luxe.
   - Métriques claires (+28% acceptation, -52% litiges, -47% churn).

4. **Conformité Totale Google Ads & RGPD** :
   - Mentions Légales complètes avec SIREN, RCS, adresse physique, téléphone et email.
   - Politique de Confidentialité conforme RGPD / CCPA avec contact DPO dédié.
   - Conditions Générales de Vente & Prestations de Services (CGV / Terms).
   - Politique de Remboursement et d'Annulation.
   - Politique de gestion des cookies avec bandeau de consentement interactif.
   - Avertissement d'indépendance et respect des marques déposées (Stripe, PayPal, etc.).
   - Support bilingue Français / Anglais.

## 🛠️ Démarrage Rapide

```bash
# Installer les dépendances
npm install

# Démarrer le serveur de développement
npm run dev

# Compiler pour la production
npm run build

# Prévisualiser le build de production
npm run preview
```

## 📦 Déploiement

Le projet compile un bundle statique ultra-rapide dans le dossier `dist/`, prêt à être déployé sur n'importe quel hébergeur (Vercel, Netlify, Cloudflare Pages, AWS S3 / CloudFront, Apache/Nginx).
